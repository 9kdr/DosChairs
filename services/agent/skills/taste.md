# House taste

Restrained, editorial, modern web looks. One idea per beat, nothing flashy.

- Type only when the brief asks for it: one strong grotesque, tight tracking, never three competing sizes. Resolve has Text+, so titles usually belong there, not in the piece.
- Motion has momentum: ease in fast, overshoot a little, settle. Stagger entrances; one element moves at a time. Springs over linear tweens.
- Color is ink, paper, and one accent. The accent is for the single most important thing on screen.
- Texture (grain, dither, halftone) sits under content at low opacity, never over text.
- Every number the editor sees becomes an Inspector control with a sane range. Everything visible is parametrized by `t`: the same seconds in, the same frame out, scrubbed in any order.
- Prefer numbers and colors over strings and booleans: they keyframe.
