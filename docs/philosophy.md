# Product philosophy: propose, never apply

Chair proposes edits and waits for a person to accept them.

- A **changeset** is a proposed edit. A **timeline** is the cut. An **adapter** is the link to one editing app.
- A pending proposed edit never changes the timeline. Accept is explicit, per change.
- Never overwrite source video or audio. The source stays as it was shot.
- The app shows its work: the thread, the activity, and the exact diff before anything applies.

New issues and pull requests can cite this note instead of re-arguing it.
